# האימון שלי · A B C

אפליקציית אימונים בעברית, מותאמת לטלפון, עם 3 אימונים ו־33 אפשרויות ביצוע.

## פתיחה והתקנה

לאחר הפעלת GitHub Pages: https://amirke.github.io/fit2/

- Android: פתח ב־Chrome, לחץ על ⋮ בתוך האפליקציה ובחר התקנה, או בחר התקנת אפליקציה בתפריט הדפדפן.
- iPhone: פתח ב־Safari, בחר שיתוף ואז הוסף למסך הבית.
- המתן בפתיחה הראשונה להודעה ״מוכן לשימוש ללא אינטרנט״ בתפריט האפליקציה.

## שימוש

בחר A/B/C, לחץ על תרגיל ובחר את הציוד הזמין. לכל סט שדה משקל נפרד הנשמר במכשיר, בנפרד לכל אימון וחלופה. ״אימון חדש״ מאפס רק את סימוני ההשלמה. ניתן להוריד ולייבא גיבוי משקלים מתפריט ⋮.

משקלי ההתחלה הם הצעות לניסיון קל בלבד. התאם אותם לטכניקה וליכולת שלך; יחידות המשקל מופיעות ליד השדות. החימום המומלץ מותאם לתרגיל ולסדר האימון. סטי החימום אינם נספרים בסטי העבודה.

המשקלים אינם נשלחים לשרת. מחיקת נתוני הדפדפן או החלפת מכשיר/כתובת עלולות למחוק את השמירה. לפני מעבר מקובץ HTML לאפליקציה המותקנת, יצא גיבוי וייבא אותו ביעד החדש.

## פרסום

GitHub Settings → Pages → Deploy from a branch → main → /(root).
המאגר מכיל אתר סטטי; אין התקנת ספריות או שלב בנייה. כל האיורים כלולים בקובץ HTML. יש לפרסם את כל הקבצים יחד.

מקורות לעקרונות העומס והחימום:
- https://www.nsca.com/education/articles/kinetic-select/introduction-to-dynamic-warm-up/
- https://www.nsca.com/education/articles/nsca-coach/using-intensity-based-on-sets-and-repetitions-over-50-years-of-experience-a-brief-overview-of-load-setting-and-programming-strategy/

האיורים נוצרו בבינה מלאכותית להמחשה; התוכנית אינה כוללת נתוני משקל אישיים שהוזנו במכשיר.
